# MVP：从《塞尔达传说：王国之泪》提炼机制并创造原创游戏

## 目的
验证 JARVIS 能否完成：成熟游戏体验分析 → 可迁移原理提炼 → 新概念创作 → 多视角分析 → 可证伪假设 → 最小原型计划。此文档是概念设计，不是玩家研究结果或市场验证。

## 输入与边界
以《王国之泪》已知设计特征为案例：组合物件与能力、利用环境规则解决问题、探索多种解法、通过学习系统规律形成新的策略。这里的心理解释属于设计假设，未经过本轮真实玩家测试。
不复制其标志性能力、角色、世界观、美术、地图或任务；不把流畅创意文本当成市场证据；不把模拟玩家观点当成真实反馈。

## 机制分析
### 观察
玩家可以组合物件与能力，利用物理、材料、地形和敌人行为处理问题。部分问题允许多种解决路径；探索、资源、能力学习和新挑战提供持续目标。

### 可迁移原理
核心不只是道具数量，而是：少量可理解规则 × 可组合对象 × 玩家自定目标，产生非预写但事后讲得通的解法。
玩家遇到问题 → 观察系统 → 提出组合假设 → 尝试 → 获得清楚反馈 → 更新对规则的理解 → 将知识迁移到新情境。
重要体验是“意外但合理”，而非随机成功。失败也应提供信息。
风险包括选择过载、建造或操作拖慢节奏、反馈含糊、内容组合重复导致惊喜衰减。

## 新游戏概念：《潮痕档案馆》（Tidemark Archive）
### 一句话
一款发生在周期性大潮改变城市结构的海港探索解谜冒险。玩家是潮痕修复师，读取物件与场所留下的使用痕迹，结合潮汐规律和居民各自的记忆，重新连接失散的人、被遗忘的用途与被掩盖的历史。

### 与案例的区别
不是以拼装交通工具为核心的开放世界。核心创造力来自把空间线索、物件使用历史和人物记忆组合成新的因果路径。规则组合与玩家自主解法是借鉴的设计原理；潮汐空间、使用痕迹、记忆冲突是本概念自己的实现。原创性仍需人工审查与市场检索。

### 世界与目标
海港由高低街区、可开合水闸、浮动集市和废弃船坞组成。大潮改变通道、货物位置、声音传播和居民路线。玩家调查一座即将封存的旧档案馆：一批居民的名字正从公共记录中消失。调查逐渐揭示，消失的不只是记录，还有城市曾经依赖的互助网络。玩家需要判断哪些痕迹可信、哪些记忆矛盾，以及公开真相会帮助或伤害谁。

### 三个系统
1. **潮汐空间**：水位按可预测周期变化，影响通路、漂浮物、机械结构和声音传播。
2. **物件使用痕迹**：磨损、修补和反复接触的位置提供部分证据；不提供万能读心，线索允许多种解释，但解释必须符合证据。
3. **居民记忆与关系**：NPC 有各自的知识边界、记忆和利害关系。玩家提供证据、改变环境或帮助居民，可能影响他们是否愿意重新审视过去、信任彼此或公开信息。

### 核心循环
观察场所与物件 → 提出历史解释 → 寻找区分不同解释的新证据 → 利用潮汐和空间规则检验 → 与居民交流 → 选择公开、隐瞒或重新解释历史 → 城市通路、关系或线索变化 → 开始下一次调查。

### 候选惊喜时刻
玩家想进入涨潮时被水隔开的仓库。铜铃磨损与水闸机械相似，一位居民记得过去曾用铃声协调夜间搬运。玩家把铜铃装到可移动栏杆上，借潮水推动栏杆，让铃声沿水道传到另一端。居民认出信号并打开维护通道。
该时刻把物件线索、潮汐、声音与居民记忆连接起来；成功不是任意魔法，而是玩家推理的结果。若移除玩家行动，通道不会自动打开；若移除居民记忆，谜题就失去叙事意义。这只是设计示例，必须测试玩家是否真觉得它合理且惊喜。

## 多视角体验假设（非真实用户研究）
- 系统探索者：可能喜欢跨系统推理；可能讨厌规则边界模糊。
- 叙事玩家：可能喜欢记忆冲突与关系变化；可能觉得调查像做作业。
- 目标导向玩家：可能喜欢案件进展；可能被分散线索拖慢。
- 休闲玩家：可能喜欢宁静探索；可能不喜欢潮汐时间压力。
- 明确规则偏好者：可能喜欢可推理证据；可能觉得多种解释等于没有答案。
- 慢节奏反感者：可能觉得单位时间内有意义决策太少。

关键张力：线索开放度 vs 推理清晰度；角色复杂性 vs 行为一致性；环境变化 vs 时间压力；多重解释 vs 明确答案。MVP 要明确取舍，而不是假设所有人都会喜欢。

## 可证伪假设
**H1 跨系统推理会产生发现感。** 玩家能组合至少两类线索，推导出非明确提示的有效方案，并解释其因果。失败信号：只能盲猜，成功后也说不清原因。
**H2 叙事反馈让解法更有意义。** 有人物 / 历史后果的解法比单纯开门更容易被记住和解释。失败信号：玩家只记住答案，角色信息不影响选择。
**H3 居民反应可信。** 玩家认为 NPC 的反应符合其已知经历、知识与利益，即使 NPC 不同意玩家。失败信号：态度变化像为推进剧情而临时安排。
**H4 自主性不等于迷失。** 玩家能说明当前目标并自行选择下一步。失败信号：频繁无效试错或必须由测试者告知答案。

## 7 天最小原型
范围：一个仓库场景、一个潮汐周期、三个可调查物件、两个掌握不同信息的居民、一个标准解法、至少两个基于线索推导的替代解法，以及会因解法而变化的一条叙事反馈。

邀请 5–8 名目标玩家无口头提示试玩。该样本用于早期机制与可用性发现，不用于宣称统计显著或代表市场。记录行为、假设、停顿、失败原因和原话；结束后询问玩家认为发生了什么、为何有效 / 无效、哪条人物信息影响了决定。

首轮内部决策门槛（非行业标准）：至少 4/5 能说清目标；至少 3/5 独立推导出非标准解法；至少 4/5 成功者能解释因果；至少 3/5 能指出人物信息如何影响判断；无关键状态矛盾破坏解法。未达门槛先诊断线索、反馈、规则、节奏或核心假设，不立即否定整个概念。
