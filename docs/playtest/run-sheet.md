# 今天开跑的操作单(第一轮真人试玩)

这一页只回答一件事:今天这一场怎么落地——在哪打开原型、按哪个按钮、记在哪、跑完当天怎么出读数。
怎么测、判定线是多少,写在 [jarvis-playtest-plan.md](../jarvis-playtest-plan.md),那一页的阈值测完不许改。

## 开跑前一次性准备(5 分钟)

1. 打开原型:双击 [prototypes/fuse-royale-prototype.html](../../prototypes/fuse-royale-prototype.html);或者
   ```bash
   python3 -m http.server 8767 --directory prototypes
   ```
   然后浏览器开 http://localhost:8767/fuse-royale-prototype.html
2. 记录表已经建好:[playtest-rows.csv](playtest-rows.csv),现在只有表头一行。**表头不要再改**,列一改判定就对不上。
3. 每场准备一个原始记录文件:`docs/playtest/raw/场次01.txt`(数字往后排),里面放那三局各自的记录文字。
   格式照 [raw/样例_机器自测.txt](raw/样例_机器自测.txt) —— 那份是我用脚本自测生成的,**不是真人读数**,只用来对格式。
4. 确认能录屏。腾讯会议 / Zoom 的屏幕共享 + 本地录制都行。**没有录像的场次整行不算数**(读数不可复核就等于没测到)。

## 每场 35 分钟,照着这个顺序做

| 时间 | 你做什么 | 他点什么按钮 | 你记什么 |
| --- | --- | --- | --- |
| 0-3 分钟 | 只念这一句,不演示:「这里能拼一台机器,拼完它自己去打,有两种赢法:把别人打掉,或者站进绿色的点里攒分。」 | 随便他看 | 他第一句问的是什么(问怎么赢还是问怎么拼) |
| 3-12 分钟 | 让他自己拼,零件上限 12 个。拼完开一局 | 「开一局:每人开局随机捡两块余料」→「跑完这一局(自动推进到结束)」 | 拼装秒、有没有想出不在 9 个预设里的组合、他讲不讲得出为什么有效 |
| 12-22 分钟 | 进第 2 局,预算收紧到 10 个,三条额度生效 | 「下一局(零件预算收紧)」→ 同样开一局、跑完 | 有没有说「想带的带不上」、赢了归因给什么 |
| 22-32 分钟 | 进第 3 局,预算收紧到 8 个 | 「下一局」→ 同样开一局、跑完 | 还在试新想法还是回到第 1 局那套、有没有故意蹲在点里不打架 |
| 32-35 分钟 | 问问卷 7 题 + 追问 A、B | — | 题 5、6、7、追问 B、两句原话 |

**三局都点「开一局:每人开局随机捡两块余料」,不要点「开这一局」。**
原因:方案里每局都应该有随机捡料和随机余料潮流,三局之间只让「零件预算」这一个变量在变,读数才干净。
真用了「开这一局」也没关系,汇总脚本会提示「三局规则不一致」,报告里注明就行。

想看过程就点「推进 1 秒」逐秒看;想快点看完就点「跑完这一局」。
这个「跑完这一局」按钮是今天新加的:原来一局约 300 跳,只能手点「推进 1 秒」,35 分钟里点不完。
仿真逻辑一行没改,还是同一套对局、还是每局固定随机数。

**引导者唯一的职责是不提示。** 不推荐零件、不解释特性继承、不告诉他怎么赢。
只有他明确问「有说明吗」的时候,才允许指出页面上已有的说明文字在哪。

他卡住了怎么办:记下他卡在哪一步、卡了多久,然后让他自己继续,别救。
这本身就是假设 4(配件语言能不能当入口)的读数。

## 每场结束以后 3 分钟

1. 每局打完让他点「复制本局记录(给引导者)」,整段复制;三局按第 1、2、3 局顺序粘进 `raw/场次NN.txt`,局与局之间空一行。
2. 把这三段变成记录表的一行:
   ```bash
   python3 docs/playtest/rowtool.py docs/playtest/raw/场次01.txt --场次 1 --组别 A >> docs/playtest/playtest-rows.csv
   ```
   脚本会填上能自动读出来的列(拼装秒、局长秒、冠军、第 3 局的组合签名),
   并在屏幕上列出**还缺哪 18 列**——那些都是要你当场看和当场问的,趁记忆还热补进那一行。
3. 当场付 30 美元。

## 当天全部跑完以后

```bash
python3 docs/playtest/tally.py docs/playtest/playtest-rows.csv
```
逐条打印每条假设的读数、95% 波动区间和判定。10 人没招满时每条都标「样本不足,只算方向」,不能当过关。
