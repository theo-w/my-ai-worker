# 招人跑第一轮:招募帖、筛选问卷、引导者脚本、记录表

配套:[jarvis-playtest-plan.md](../jarvis-playtest-plan.md)(判定标准在那份里,这份只管怎么把人找来、怎么问、怎么记)。
原型文件:[prototypes/fuse-royale-prototype.html](../../prototypes/fuse-royale-prototype.html),双击就能开,不用装东西、不用联网。

## 招募帖(中文,发 TapTap 相关游戏评论区、贴吧、Reddit 中文版块)

> 找一个 35 分钟的线上小游戏测试,报酬 30 美元。
> 你收到一个网页文件,里面能拼一台机器:贴轮子它会走,贴长矛它能打人,贴火焰余料它全身带火。拼完它自己去打另外 9 台机器,有两种赢法:把别人打掉,或者站进绿色的点里攒分。
> 我要测的是「不给教程,你能不能自己想到怎么拼」,所以我全程不会提示你。
> 要求:近 30 天玩过下面任一游戏并自己造过东西 —— Survival & Craft、Ride Master、Rescue Machine!(造过载具、车、武器都算)。
> 流程:线上 1v1,我共享屏幕陪你 35 分钟,你开录屏。报名请回答文末 4 个问题。

## 招募帖(英文,发 Reddit 相关版块)

> Paid 35-minute remote playtest, USD 30.
> You get a single HTML file: you assemble a machine (wheels make it drive, a spear makes it hit, scrap makes it carry fire), then it fights 9 other machines on its own. Two ways to win: knock everyone out, or stand in the green zone and fill a score meter.
> I am testing whether people can figure out the assembly without a tutorial, so I will not hint at anything.
> Requirement: you have played and *built things in* Survival & Craft, Ride Master or Rescue Machine! in the last 30 days.
> Format: 1-on-1 remote, 35 minutes, you record your screen. Answer the 4 screening questions to apply.

## 筛选问卷(4 题,答完才发文件)

1. 近 30 天你最常玩的两个游戏是什么?
2. 你在这些游戏里自己造过载具 / 车 / 武器吗?造过什么?(一句话)
3. 你主要玩手游、主机还是 PC?
4. 能不能开录屏并接受 35 分钟线上 1v1?(不能就不安排)

筛选标准:第 1、2 题必须命中拼装/生存类或射击对抗类,两类各招 5 人;朋友最多算 2 人;答不出第 2 题具体造过什么的淘汰。

## 给试玩者的准备说明(报名成功后发给他)

- 下载那个 HTML 文件,双击打开。Chrome 或 Edge 都行,不用联网。
- 打开录屏(手机拍屏幕也行,但要能看清读数面板)。
- 这一轮不需要账号、不收费、不会收集你的名字;记录表里只用场次编号。
- 一句话预告:「我不会提示你,你想问什么都可以问,但我只能指出页面上的说明在哪。」

## 引导者逐字脚本(照着念,不要自由发挥)

开场(第 0-3 分钟,只念这一句,不演示):

> 「这里能拼一台机器,拼完它自己去打另外 9 台。有两种赢法:把别人打掉,或者站进绿色的点里攒满 75 分。你随便试,我不提示。」

三局的切换(第 12、22 分钟):

> 「下一局零件上限收紧了,你要么用更少的零件保住强度,要么换思路。」
> (念完就停。不解释怎么换思路。)

他问「有说明吗」/「这个零件干什么用」时,唯一允许的回应:

> 「页面左边每个零件都有一行说明,你可以自己看。」

他问「这样拼对吗」/「我该贴哪」时:

> 「没有对错,你拼完点『开这一局』看它自己怎么动。」

每局结束必须问的两句(照抄他的回答,不改写):

> 「这局赢/输是因为什么?」
> 「赢的那局里,你觉得是你的机器厉害,还是你抢到了好位置?」

收尾问卷 7 题加 2 个追问的题目原文在 [jarvis-playtest-plan.md](../jarvis-playtest-plan.md) 里。

最后一步:让他点页面上的「复制本局记录(给引导者)」,把弹出在下方文本框里的整段文字贴给你,你粘进记录表对应行。三局各记一次。

## 记录表

CSV 模板(引导者一人一行,列名固定,汇总脚本读它):

把下面这一行原样粘进本地文件 `docs/playtest/playtest-rows.csv` 的第一行:

```
场次,组别,有录像,第一句问的,误解次数,有人说这台肯定赢,第1局_拼装秒,第1局_首次开局秒,第1局_局长秒,第1局_非预设组合,第1局_能讲因果,第1局_冠军,第2局_拼装秒,第2局_局长秒,第2局_额度反应,第2局_紧张感,第2局_归因,第2局_蹲点不打架,第2局_用过别人的造法,第2局_改过再用,第2局_冠军,第3局_拼装秒,第3局_局长秒,第3局_换想法,第3局_组合签名,第3局_冠军,题5_愿意分享,题6_选择,题7_有新东西,追问B_要停下挑,原话_因果,原话_归因
```

每列允许的取值:

| 列 | 取值 |
| --- | --- |
| 组别 | A(拼装生存类)/ B(射击对抗类) |
| 有录像 | 是 / 否(否的行汇总时整行剔除) |
| 第1局_非预设组合 | 是 / 否(他想到 9 个预设之外的组合) |
| 第1局_能讲因果 | 是 / 否(他能说出为什么这样有效) |
| 第2局_额度反应 | 合理 / 带不上 / 没注意 |
| 第2局_紧张感 | 有 / 无(第 2 局他有没有报告紧张) |
| 第2局_归因 | 机器 / 位置 / 其他 |
| 第2局_蹲点不打架 | 是 / 否(明显蹲在点里躲着打) |
| 第2局_用过别人的造法 / 第2局_改过再用 | 是 / 否 |
| 第3局_换想法 | 换 / 不换(第 3 局组合和第 1 局不同即「换」) |
| 第3局_组合签名 | 把记录框里的零件清单原样粘过来(用来数组合有没有收敛) |
| 第 N 局_冠军 | 我的机器 / 或预设名(记录框里的「本局结果」那行照抄) |
| 题5_愿意分享 | 是 / 否 |
| 题6_选择 | 捡枪 / 继续拼 |
| 题7_有新东西 | 是 / 否 |
| 追问B_要停下挑 | 要 / 不要 |
| 原话_因果 / 原话_归因 | 照抄,不许改写、不许总结 |

## 跑完之后

```bash
python3 docs/playtest/tally.py docs/playtest/playtest-rows.csv
```

它按 [jarvis-playtest-plan.md](../jarvis-playtest-plan.md) 的通过线和失败线逐条打印读数,每条都带 10 人样本的波动区间(只判方向,不判达标)。判定结果连同原话摘录一起写回报告的「真人试玩这一关」一节。

页面记录框里还有两个数值得单独看,但第一轮不作为判定项:**从打开页面到第一次开局的秒数**(没有教程的冷启动)、**每局拼装用时占局长的比例**(现在只有观战版,假设 7 要等一键焊改完才算测过)。
